``` ### En GitHub solo necesitas tener esto ```text tu-repositorio/ │ ├── index.html ├── menu.html └── Valentine.mp3 ``` **No cambies el nombre de `Valentine.mp3`** si el archivo está escrito exactamente así. Ahora, cuando Kass abra la página: **1.** Aparece: > Click to enter ♡ **2.** Presiona el botón `♡`. **3.** `Valentine.mp3` comienza inmediatamente. **4.** La pantalla hace una transición suave. **5.** Aparece tu `¿Te gusto? :3`. **6.** La canción sigue sonando mientras usa la página. Y como el clic ocurre antes de `musica.play()`, estás usando la forma normal que permiten los navegadores para reproducir audio con sonido.
